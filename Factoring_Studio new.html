The Box (Area) Method

The box method turns factoring a trinomial ax² + bx + c into a fill-in-the-grid puzzle. Here's the process:

1
Draw a 2×2 box. Put ax² in the top-left cell and c in the bottom-right cell.
2
Multiply a × c. Find two numbers that multiply to ac and add to b.
3
Place those two numbers (as x-terms) into the other two cells — either arrangement works.
4
Find the GCF of each row (these become one binomial's terms) and the GCF of each column (these become the other binomial's terms).
5
Write the two binomials as your final answer.

Example A — Leading coefficient of 1

x² + 7x + 12
1
a = 1, c = 12, so ac = 12. Find two numbers that multiply to 12 and add to 7: 3 and 4.
2

Perfect Square Trinomials

A perfect square trinomial comes from squaring a binomial:

(a + b)² = a² + 2ab + b²
(a − b)² = a² − 2ab + b²

Instead of using the box method, you can spot this pattern directly with a 3-question test:

1
Is the first term a perfect square? Take its square root → call it a.
2
Is the last term a perfect square? Take its square root → call it b.
3
Does the middle term equal 2ab (matching sign)? If yes to all three → it's a perfect square trinomial: (a + b)² or (a − b)².

Example 1: x² + 8x + 16

√x² = x, √16 = 4. Check: 2(x)(4) = 8x ✓ matches, and the sign is positive.
x² + 8x + 16 = (x + 4)²

Example 2: x² − 14x + 49

√x² = x, √49 = 7. Check: 2(x)(7) = 14x ✓ matches, and the sign is negative.
x² − 14x + 49 = (x − 7)²

Example 3: 4x² + 20x + 25

√4x² = 2x, √25 = 5. Check: 2(2x)(5) = 20x ✓ matches, and the sign is positive.
4x² + 20x + 25 = (2x + 5)²
Always check your answer by expanding it back out — e.g., (x+4)² = x² + 8x + 16 ✓. This habit catches sign errors immediately.

Difference of Squares

A binomial (only two terms) factors instantly if it fits this pattern:

a² − b² = (a + b)(a − b)

How to Recognize It

1
There are exactly two terms (no middle term).
2
Both terms are perfect squares.
3
The two terms are separated by a subtraction sign.

Example 1: x² − 36

√x² = x, √36 = 6.
x² − 36 = (x + 6)(x − 6)

Example 2: 9x² − 4

√9x² = 3x, √4 = 2.
9x² − 4 = (3x + 2)(3x − 2)

Example 3: 25x² − 1

√25x² = 5x, √1 = 1.
25x² − 1 = (5x + 1)(5x − 1)
Important: a sum of squares, a² + b², does not factor using real numbers — only a difference of squares works with this pattern.

Factor by Grouping

Grouping is used for polynomials with four terms (or for trinomials after splitting the middle term, connecting back to the box method).

1
Split the four terms into two groups of two.
2
Factor the GCF out of each group separately.
3
If both groups now share the same binomial factor, factor that binomial out.

Example 1: x³ + 5x² + 3x + 15

Group: (x³ + 5x²) + (3x + 15)
Factor each group: x²(x + 5) + 3(x + 5)
Both groups share (x + 5) — factor it out.
x³ + 5x² + 3x + 15 = (x + 5)(x² + 3)

Example 2: A trinomial split using grouping — 2x² + 7x + 3

From the box method, we know 6 and 1 multiply to ac = 6 and add to b = 7. Split the middle term: 2x² + 6x + x + 3
Group: (2x² + 6x) + (x + 3) = 2x(x + 3) + 1(x + 3)
Both groups share (x + 3) — factor it out.
2x² + 7x + 3 = (x + 3)(2x + 1)
This is the exact same answer the box method gave — grouping and the box method are really the same idea, shown two different ways.
